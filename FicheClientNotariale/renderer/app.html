🖥 Démarrer le serveur local
Pour activer le mode multi-postes en réseau local :
1. Installer Node.js sur le PC serveur
2. Télécharger et démarrer le serveur FCN
Puis exécuter : node fcn-serveur.js
Mode serveur : Toutes les instances connectées partagent les mêmes données en temps réel via WebSocket. Les modifications sont immédiatement visibles sur tous les postes du réseau.
